# 🏥 Clínica SaúdeDigital — Projeto Integrador (A3)

Sistema de Gerenciamento de Banco de Dados Relacional (`saude_digital_a3`) e aplicação CRUD desenvolvidos para a disciplina de Banco de Dados (UNIFACS / Trilha Oracle Academy).

## 📋 Sobre o Projeto
Solução desenvolvida para modernizar o atendimento da **Clínica SaúdeDigital**, substituindo controles manuais por um banco de dados normalizado até a 3ª Forma Normal (3FN) e integrado a uma interface funcional de prontuário eletrônico.

## 🛠️ Tecnologias Utilizadas
* **SGBD:** MySQL / MariaDB (hospedado em Oracle VM VirtualBox)
* **Modelagem e Administração:** Mermaid / MySQL Workbench / DBeaver
* **Aplicação CRUD:** Python 3 + Streamlit + Pandas + MySQL Connector

## 📂 Estrutura do Repositório
* `/diagramas` — Diagrama Entidade-Relacionamento (DER) em imagem e código Mermaid
* `/sql` — Scripts modulares: `01_ddl_estrutura.sql`, `02_dml_dados.sql` e `03_dql_consultas.sql`
* `/app` — Código-fonte da aplicação CRUD (`app.py` e `requirements.txt`)
* `Relatorio_Tecnico_SaudeDigital_A3.pdf` — Documentação técnica completa (regras de negócio, 3FN e dicionário de dados)

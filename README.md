# 🏥 Clínica SaúdeDigital — Projeto Integrador (A3)

Sistema de Gerenciamento de Banco de Dados Relacional e aplicação CRUD desenvolvidos para a disciplina de Banco de Dados (UNIFACS / Trilha Oracle Academy).

## 📋 Sobre o Projeto
Solução desenvolvida para modernizar o atendimento da **Clínica SaúdeDigital**, substituindo controles manuais por um banco de dados normalizado até a 3ª Forma Normal (3FN) e integrado a uma interface funcional.

## 🛠️ Tecnologias Utilizadas
* **SGBD:** MySQL / MariaDB (hospedado em Oracle VM VirtualBox)
* **Modelagem e Administração:** Mermaid / MySQL Workbench / DBeaver
* **Aplicação CRUD:** [Colocar linguagem/framework usado, ex: Python + Streamlit]
